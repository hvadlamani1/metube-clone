# metube-clone

A generic, reusable template for building a small media catalog of **channels** and **books**. Fork it, copy the templates, and fill in your own content.

## Structure

```
templates/
  channel/
    channel.md      # Markdown template for a channel entry
    channel.json    # JSON template for a channel entry
  book/
    book.md         # Markdown template for a book entry
    book.json       # JSON template for a book entry
```

## Usage

1. Copy a template into a new file, e.g. `channels/my-channel.md` or `books/my-book.json`.
2. Replace every `{{placeholder}}` with your own values.
3. Commit your entries.
